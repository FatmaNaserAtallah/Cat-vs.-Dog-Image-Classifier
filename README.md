# Cat-vs.-Dog-Image-Classifier
This repository contains a deep learning model that classifies images as either cats or dogs with 90% accuracy.
Project Overview

- Model Type: Convolutional Neural Network (CNN) for binary image classification
- Accuracy: 90% on test set
- Framework: TensorFlow/Keras
- Dataset: [Dogs vs. Cats dataset]((https://drive.google.com/drive/folders/1otQhDGeM5m7O67pvC4Jk241unqrAlj6K?usp=drive_link))
